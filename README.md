# Python Mini Applications

## Description
This project contains three simple Python applications combined into a single file named `app.py`.

## Applications

### 1. Student Marks Calculator
- Calculates the average of student marks.
- Finds the highest mark.
- Finds the lowest mark.
- Uses Python functions.

### 2. Simple Calculator
- Performs addition.
- Performs subtraction.
- Performs multiplication.
- Performs division.

### 3. Simple Greeting Bot
- Greets users with simple responses.
- Matches user input with predefined keywords.
- Runs continuously until the user types `bye`.
- Stores conversation history using a list of dictionaries.

## Technologies Used
- Python 3
- Dictionaries
- Lists
- Functions
- Conditional Statements
- Loops
