# Python Beginner Project

## Project Title
Simple Calculator and Greeting Bot

## Description
This project contains two beginner-friendly Python programs.

### 1. Greeting Bot
- Asks the user's name
- Uses f-strings
- Uses if-else conditions
- Displays a personalized greeting

### 2. Simple Calculator
- Addition
- Subtraction
- Multiplication
- Division
- Handles division by zero

## Technologies Used
- Python
- HTML
- CSS
- JavaScript
- Git
- GitHub

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project in VS Code.
4. Run the following command:

```bash
python main.py
```
